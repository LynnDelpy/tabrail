- (direction by user) escape to leave naming of something
- (note) Naming sites (menu.rs): Rename tab (command-prompt -I name, rename-window), Rename group (tabrail-act rename-group), New group from a tab row (@id) and from group/empty rows (pane as pNN)
- (note) Cause: tmux defaults status-keys to vi when EDITOR/VISUAL contain 'vi' (user: EDITOR=/usr/bin/vim); vi prompt: Esc enters normal mode, more Esc do nothing, only q or C-c cancel; emacs: one Esc cancels; no per-prompt key setting in tmux
- (note) confirm-before (Close x) with vi keys: Esc does not cancel either, prompt stays open
- (note) Test pitfall: command-prompt/confirm-before from the CLI block until dismissed; use -b
- (decision by user) Fix: tabrail's naming prompts become a popup name field in tabrail-pick's style; Esc cancels, Enter saves; tmux's own prompts and status-keys untouched (rejected: status-keys emacs in tabrail.tmux, user-only tmux.conf line)
